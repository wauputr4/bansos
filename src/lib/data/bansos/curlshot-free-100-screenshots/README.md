# ✅ CurlShot — API Screenshot Website Gratis 100 per Bulan

**Provider:** CurlShot

API screenshot website: ubah URL apa pun jadi gambar PNG, JPEG, WebP, atau PDF lewat satu request GET. Paket gratis 100 screenshot per bulan tanpa kartu kredit, cocok untuk thumbnail link, gambar Open Graph, arsip halaman, dan agent AI.

> **Status:** Aktif

⏰ **Info Waktu:** Paket gratis permanen, kuota direset setiap bulan

## Keuntungan

- 100 screenshot gratis setiap bulan, tanpa kartu kredit
- Output PNG, JPEG, WebP, atau PDF; screenshot satu halaman penuh, preset perangkat mobile/tablet, mode gelap, dan elemen tertentu via CSS selector
- Pemblokiran iklan dan banner cookie dapat diaktifkan di API; aktif secara default melalui MCP
- Server MCP hosted untuk Claude Code, Cursor, dan agent AI lain, plus node komunitas n8n

## Persyaratan

- Daftar akun di curlshot.com dengan nama, email, dan password
- Buat API key di dashboard

## Tips

Coba dulu tanpa akun di https://curlshot.com/tools/full-page-screenshot. Dokumentasi API: https://curlshot.com/docs
