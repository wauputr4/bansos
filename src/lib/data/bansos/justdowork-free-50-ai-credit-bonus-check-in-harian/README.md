# ✅ JustDoWork Free $50 AI Credit + Bonus Check-in Harian

**Provider:** JustDoWork

JustDoWork memberikan kredit API senilai $50 untuk pengguna baru yang mendaftar dengan akun GitHub, ditambah bonus check-in harian yang besarannya bervariasi (contoh: $23,66 pada 19 Agustus 2026). Kredit dapat dipakai untuk Claude Opus 5 dan Claude Opus 4.8 melalui endpoint Anthropic maupun OpenAI, dengan tarif sekitar $0,25 per satu juta token.

> **Status:** Aktif

⏰ **Info Waktu:** Ketersediaan dan besaran kredit mengikuti kebijakan JustDoWork

## Keuntungan

- Kredit API senilai $50 untuk pengguna baru
- Bonus check-in harian, besaran bervariasi
- Akses Claude Opus 5 dan Claude Opus 4.8
- Mendukung endpoint Anthropic dan OpenAI

## Persyaratan

- Mendaftar dengan akun GitHub (pendaftaran lewat email tidak tersedia)
- Umur akun GitHub minimal 1 tahun
- Menyelesaikan verifikasi Cloudflare Turnstile saat mendaftar
- Mendaftar lewat tautan undangan yang tersedia
- Membuat API key di dashboard lalu arahkan klien ke https://api.justwoker.icu/v1

## Tips

Model yang tersedia hanya varian thinking dari Claude Opus 5 dan Opus 4.8, jadi tidak ada model ringan untuk tugas sederhana. Prompt caching tidak aktif sehingga konteks panjang dihitung penuh setiap permintaan, pakai percakapan pendek agar kredit lebih awet. Nama model harus ditulis lengkap dengan akhiran -thinking.
