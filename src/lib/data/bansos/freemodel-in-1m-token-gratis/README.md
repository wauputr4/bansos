# ✅ FreeModel.in — Gratis 1M Token API per Bulan, Semua 31 Model

**Provider:** FreeModel.in

FreeModel (freemodel.in) adalah gateway API OpenAI-compatible dengan 31 model — Claude Opus 5, Claude Fable 5, GPT-6.1, Gemini 3.1 Pro, Grok 4.6, GLM 5.3, DeepSeek V4, dan lainnya — semuanya bisa diakses dari free tier. Gratis 1 juta token per bulan tanpa kartu kredit, allowance reset bulanan, dengan streaming, tool calling, vision, reasoning, JSON mode, dan embeddings aktif di semua plan. Cukup ganti base URL ke https://freemodel.in/v1 dan semua tool OpenAI-compatible (Cursor, Cline, Claude Code, opencode, Kilo Code) langsung jalan. Kelebihan allowance ditagih ke balance per harga model — kalau balance kosong, request ditolak dengan HTTP 402 yang jelas, tidak pernah surprise invoice. Catatan: ini situs berbeda dari FreeModel.dev yang sudah pernah dilisting sebelumnya.

> **Status:** Aktif

⏰ **Info Waktu:** Halaman pricing menyebut free tier Free Forever, tapi tidak ada tanggal resmi; mengikuti kebijakan operator (dicek Oktober 2026)

## Keuntungan

- Free tier 1 juta token per bulan — tanpa kartu kredit, reset tiap bulan (disebut Free Forever oleh situs)
- Semua 31 model terbuka di semua plan termasuk Free: Claude Opus 5, Claude Fable 5, GPT-6.1, Gemini 3.1 Pro, Grok 4.6, GLM 5.3, DeepSeek V4
- Streaming, tool calling, vision, reasoning, JSON mode + embeddings (text-embedding-3-small/large) aktif di semua plan
- OpenAI-compatible — ganti base URL ke https://freemodel.in/v1, langsung jalan di Cursor, Cline, Claude Code, opencode, Kilo Code
- Rate limit free tier 60 request/menit dan 100k token/menit
- Setelah allowance habis request ditagih ke balance per harga model; balance kosong = HTTP 402 jelas, bukan tagihan mengejutkan

## Persyaratan

- Daftar dengan email atau akun Google (password min. 8 karakter), tanpa kartu kredit
- Buat API key di dashboard (format fm_... — key hanya ditampilkan sekali, langsung disalin)
- Allowance bulanan dipakai duluan; token dihitung gabungan prompt + completion
- Kelebihan pakai ditagih ke balance. Bila melakukan top-up, ikuti metode, jaringan, dan alamat pembayaran persis seperti yang ditampilkan di dashboard; saldo kosong menghasilkan HTTP 402
- Rate limit 60 req/menit di-enforce per akun di free tier
